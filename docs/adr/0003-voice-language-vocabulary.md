# 0003 — Voice, language and action vocabulary

Status: accepted, 22 Oct 2026 (owner, `/loop-me` session for #5). Spec: #3.

## Decision

- **Language:** English only for now.
- **Voice:** a well-travelled local friend. Warm, concrete, honest. It always says what is different from the place you wanted.
  - Never empty poetry ("Your kind of elsewhere", "Taste has no borders").
  - Never system words (entity, signal, resolve, candidates, Qloo on cards).
  - Short, active sentences. A button says exactly what happens.
  - Disclaimers appear once (footer, plus once on place and Swap detail), never on every card.
- **Core action:** "Find its twin", everywhere (buttons, Home, Place page). The menu item is "Swap".
- **Brand terms:** "Taste Passport" and "stamp" stay, always with the function next to them the first time on a page (e.g. "Your Taste Passport: what you love, so we can pick for you"). "Visa" and "signal" go.


## Amendment — 25 Oct 2026: Twin vocabulary

Owner selected Twin for visible navigation and tabs, keeping Find its twin as
the main action. Keep / Delete / Ignore are explicit per-search choices. Delete
excludes a trait, never Passport data. DNA is a light metaphor with concrete
explanations, no invented matching percentages. Legacy Swap links stay valid.
