# Beesyde quiz illustrations

38 original flat SVG scenes authored for Taste Chemistry on 26 October 2026.
No third-party stock, generated portraits, official album art, film posters or
trademarks are embedded. Music and film cards use interpretive motifs (records,
piano, drum machine, tropical foliage, train, rain, Paris streets, desert car),
with the actual title/artist always shown separately in accessible text.

Artwork mapping lives in `src/components/quiz-artwork.tsx`. Illustrations are
decorative; answer text carries the meaning. Native SVGs are served locally.
Unselected choices are muted; selecting reveals their full palette with a short,
restrained movement, disabled for reduced motion. There are no new runtime
packages, external asset hosts, tracking requests or licensing dependencies.

The owner referenced vector-graphics and Magic UI. The former targets PixiJS,
which this project does not use; the latter explicitly excludes application form
controls. Neither framework was added. GSAP and the established fonts remain.
